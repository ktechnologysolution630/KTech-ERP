## 2. เมนูหลัก (top menu)

`ซื้อ` · `ขาย` · `การเงิน` · `สินค้า` · `บัญชี` · `รายงาน` · `เริ่มระบบ` · `อื่นๆ`

12 ระบบที่ทำงานเชื่อมกัน: จัดซื้อ/รับสินค้า, เจ้าหนี้และค่าใช้จ่ายอื่น, ขาย/จองสินค้า, ลูกหนี้และรายได้อื่น, สินค้าคงคลัง, เช็คและเงินฝากธนาคาร, VAT และภาษีหัก ณ ที่จ่าย, บัญชีแยกประเภท, สินทรัพย์ถาวร, วิเคราะห์การขาย, วิเคราะห์การซื้อ, รักษาความปลอดภัยข้อมูล

### เมนูย่อยที่พบ (จาก tutorial ทางการ + รายงานสหกิจ)

- **เริ่มระบบ**: กำหนดบริษัทใหม่, เปิดแฟ้มข้อมูลใหม่ (เลือกผังบัญชีอัตโนมัติได้), กำหนดค่าเริ่มต้น (รายละเอียดกิจการ / เรื่องทั่วไป), กำหนดรอบบัญชี, กำหนดตารางข้อมูล (รหัสต่าง ๆ), กำหนดผังบัญชี, **กำหนดการเชื่อมต่อบัญชี** (ผูกเอกสาร → รหัสบัญชีสำหรับ Auto-GL), **กำหนดเลขที่เอกสาร**, กำหนดค่าเริ่มต้นระบบขาย/ซื้อ/สินค้า, ยอดยกมา (ลูกหนี้, เจ้าหนี้, สินค้า, เช็ครับ/จ่ายล่วงหน้า, ยอดบัญชี)
- **Master**: พนักงานขาย, ลูกค้า, เจ้าหนี้, สินค้า/วัตถุดิบ, สินค้าบริการ, สินค้าชุด, บัญชีเงินฝากธนาคาร
- **ซื้อ**: ซื้อเงินสด (HP), ใบสั่งซื้อ (PO), ซื้อเงินเชื่อ/รับสินค้า (RR), ลดหนี้/ส่งคืนสินค้า, ค่าใช้จ่ายอื่น ๆ
- **ขาย**: ใบเสนอราคา, ใบสั่งขาย (SO), ขายเงินสด (HS), ขายเงินเชื่อ (IV), ลดหนี้/รับคืนสินค้า, ขายสินค้าบริการ
- **การเงิน**: รับเงิน › รับชำระหนี้ (RE) · จ่ายเงิน › จ่ายชำระหนี้ (PS) · ธนาคาร › เช็ครับ / เช็คจ่าย / ผ่านเช็ค / Statement · หักภาษี ณ ที่จ่าย
- **สินค้า**: จ่ายวัตถุดิบเพื่อผลิต, ปรับปรุงค่าแรงผลิต, รับสินค้าสำเร็จรูป, ปรับปรุงต้นทุนสินค้า, โอนย้ายระหว่างคลัง
- **บัญชี**: ลงประจำวัน (สมุดรายวันรับ RV / จ่าย PV / ทั่วไป JV), ผ่านรายการไปแยกประเภท (เฉพาะ 1.5), สินทรัพย์ถาวร (กลุ่มบัญชีทรัพย์สิน, ค่าเสื่อม)
- **อื่นๆ**: จัดเรียงข้อมูล, คำนวณยอดใหม่, สำรอง/ตรวจสอบ/นำข้อมูลสำรองกลับ, **ปิดประมวลผลสิ้นปี**, ระบบความปลอดภัย (สิทธิ์ผู้ใช้), แก้ไขแบบฟอร์ม, ลงทะเบียนโปรแกรม

## 3. ประเภทเอกสารและ Flow

| ย่อ | เอกสาร | ลงบัญชีอัตโนมัติ (ตัวอย่างจริงจากรายงาน) |
|---|---|---|
| PO | ใบสั่งซื้อ | ไม่ลงบัญชี (ยังไม่เกิดรายการ) แต่ติดตามยอดค้างรับ |
| HP | ซื้อเงินสด | Dr ซื้อ/ค่าใช้จ่าย, Dr ภาษีซื้อ / Cr เงินสด-เงินย่อย |
| RR | ซื้อเงินเชื่อ = ใบรับสินค้า (อ้าง PO ได้หรือไม่ก็ได้) | Dr ซื้อ, Dr ภาษีซื้อ / Cr เจ้าหนี้การค้า + บวกสต็อก |
| RRGR* | ส่งคืนสินค้า/ลดหนี้ซื้อ (*รหัสตั้งเองได้) | กลับรายการ RR |
| PS | จ่ายชำระหนี้ (เลือก RR + ลดหนี้มาตัด) | Dr เจ้าหนี้ / Cr ธนาคาร-เช็ค, หัก ภ.ง.ด.3/53 |
| PV | สมุดรายวันจ่าย (ค่าใช้จ่ายจ่ายตรง) | Dr ค่าใช้จ่าย / Cr เงินสด |
| QT | ใบเสนอราคา | ไม่ลงบัญชี, ดึงไป SO/IV ได้ไม่ต้องคีย์ซ้ำ |
| SO | ใบสั่งขาย (จองสินค้า) | ไม่ลงบัญชี, เปิด IV ได้หลายครั้งจนส่งครบ |
| HS | ขายเงินสด | Dr เงินสด / Cr ขาย, Cr ภาษีขาย + ตัดสต็อก |
| IV | ขายเงินเชื่อ = ใบกำกับสินค้า/ใบกำกับภาษี | Dr ลูกหนี้ / Cr ขาย, Cr ภาษีขาย + ตัดสต็อก |
| IVSR* | รับคืนสินค้า/ลดหนี้ขาย | กลับรายการ IV |
| RE | รับชำระหนี้ (ติ๊กเลือก IV) | Dr ธนาคาร / Cr ลูกหนี้ (เศษสตางค์ → รายได้อื่น) |
| RV / JV | สมุดรายวันรับ / ทั่วไป | คีย์เอง |

```
ซื้อ:  PO ──► RR (รับของ+ตั้งหนี้+สต็อก+ภาษีซื้อ) ──► PS (จ่าย+WHT+เช็ค)
             └► RRGR ส่งคืน/ลดหนี้
       HP ซื้อสด, PV ค่าใช้จ่ายจ่ายตรง
ขาย:  QT ──► SO ──► IV (ส่งของ+ตั้งหนี้+ตัดสต็อก+ภาษีขาย) ──► RE (รับเงิน/เช็ครับ)
                    └► IVSR รับคืน/ลดหนี้
       HS ขายสด
```

หลักการสำคัญ: ผู้ใช้คีย์เฉพาะเอกสารซื้อขายประจำวัน แล้ว Express ผ่านรายการไปทุกระบบเอง (ลูกหนี้/เจ้าหนี้, สต็อก, VAT, GL, สถิติขาย/ซื้อ) ตาม "การเชื่อมต่อบัญชี"

ฟีเจอร์ระหว่างคีย์: แสดงกำไรขั้นต้นต่อบิล, เตือนขายต่ำกว่าทุน, เตือนต่ำกว่าจุดสั่งซื้อ, เตือนเกินวงเงินเครดิต, แยก VAT ขอคืนได้/ไม่ได้, ธุรกิจบริการลง VAT ตอนรับ/จ่ายเงิน, สูงสุด 999 บรรทัดต่อเอกสาร

## 4. เลขที่เอกสาร

ตัวอย่างที่พบ: `HP1706/062`, `RR1706/021`, `PS1706/011`, `PV1706/026`, `HS1706002`, `IV17/06003`, `RE17/06003`
รูปแบบ = **คำนำหน้า + ปี 2 หลัก + เดือน + ลำดับ** (ตัวคั่นตั้งได้เอง ผ่านเมนู "กำหนดเลขที่เอกสาร") — KTech ใช้ `PO-202611-001` ซึ่งเทียบเท่ากันแล้ว

## 5. รายงานและแบบฟอร์ม

- รายงาน: ภาษีซื้อ / ภาษีขาย, สินค้าถึงจุดสั่งซื้อ, สินค้าค้างส่ง, วิเคราะห์การขาย/การซื้อ, ทะเบียนเช็ครับ/จ่าย, Statement ธนาคาร/กระทบยอด, สมุดรายวัน, งบการเงิน (มีคลิปแยก), ภ.ง.ด. (คลิป newrwt)
- ยังไม่ยืนยันจากแหล่งที่อ่าน: ชื่อรายงานสต็อกการ์ด, งบทดลอง (แทบแน่นอนว่ามี แต่ไม่พบในเอกสาร)
- ฟอร์มพิมพ์: ใบเสนอราคา, บิลเงินสด, ใบสั่งขาย, ใบกำกับสินค้า/ใบกำกับภาษี (ตั้งได้ 9 แบบ), ใบสั่งซื้อ, ใบรับสินค้า (3 แบบ), ใบเสร็จ, เอกสารแนบตัดจ่ายชำระหนี้; แก้ไขแบบฟอร์มได้เอง

## 6. Gap เทียบ KTech-ERP (main @ 96c9888)

| Express | KTech-ERP ตอนนี้ | สถานะ |
|---|---|---|
| ผังบัญชี + การเชื่อมต่อบัญชี + Auto-GL | `gl_accounts.system_key`, `journal_entries` สมุด PU/SA/RV/PS/GL, หน้า สมุดรายวัน/งบทดลอง/แยกประเภท | ✅ มีแล้ว (PR #55) |
| PO → RR → PS | `pos` → `receipts` + `invoices` (บิลเจ้าหนี้) → `pvs` (+WHT) | ✅ มี (ชื่อ PV ของเรา = PS ของ Express) |
| HP ซื้อเงินสด / PV ค่าใช้จ่าย | sales_docs `EXP` ใบสำคัญจ่าย | ✅ ใกล้เคียง |
| RRGR ส่งคืน/ลดหนี้ซื้อ | stock issue `RETURN_SUPPLIER` (สต็อกเท่านั้น) | ⚠️ ขาดใบลดหนี้เจ้าหนี้ + กลับรายการ GL/ภาษีซื้อ |
| QT | sales_docs `QT` | ✅ |
| SO ใบสั่งขาย/จองสินค้า | ไม่มี | ❌ ขาด |
| IV / RE / ลดหนี้ขาย | `ar_invoices`, `ar_receipts`, `ar_credit_notes` | ✅ |
| HS ขายเงินสด | `STI` / `REC` | ✅ ใกล้เคียง |
| ขาย/ส่งของ ตัดสต็อก + ต้นทุนขาย | IV ไม่ผูกสต็อก | ❌ ขาด (ต้องมาพร้อม SO) |
| ต้นทุนถัวเฉลี่ย (moving average) | ใช้ `unit_cost` ล่าสุด | ❌ ขาด |
| หลายคลัง + โอนย้ายระหว่างคลัง | `warehouse_name` เป็นข้อความ, มี TRF | ⚠️ ยังไม่มี master คลัง |
| สต็อกการ์ด | ประวัติ movement ในหน้า stock | ⚠️ มีบางส่วน ยังไม่มียอดคงเหลือ/มูลค่าวิ่งต่อรายการ |
| จุดสั่งซื้อ / รายงานถึงจุดสั่งซื้อ | มี reorder dialog | ✅ (ยังไม่ขึ้น dashboard) |
| เช็ครับ/จ่าย, ผ่านเช็ค | หน้า `cheques`, `cash-bank` | ⚠️ ยังไม่มีขั้น "ผ่านเช็ค" + กระทบยอดธนาคาร |
| ภาษีซื้อ / ภาษีขาย / ภ.ง.ด. | `input-vat`, `output-vat`, `wht-report` | ✅ |
| ยอดยกมา (ลูกหนี้/เจ้าหนี้/สินค้า/บัญชี) | มีเฉพาะบางส่วน | ❌ ขาดหน้าจอยอดยกมารวม |
| ปิดงวด / ปิดบัญชีสิ้นปี | ไม่มี | ❌ ขาด (ควรล็อกเอกสารย้อนงวด) |
| พนักงานขาย, วงเงินเครดิตลูกค้า + เตือน | ไม่มี (วงเงินมีเฉพาะผู้ขาย) | ❌ ขาด |
| วิเคราะห์การขาย/ซื้อ, กำไรขั้นต้นต่อบิล | ยังไม่มี | ❌ ขาด |
| สินทรัพย์ + ค่าเสื่อม | `assets` (มีค่าเสื่อมใน domain) | ⚠️ ยังไม่ลง GL |
| สิทธิ์ผู้ใช้, แก้ฟอร์ม, เลขที่เอกสาร | roles, `settings/forms`, `settings/doc-numbers` | ✅ |
| สำรอง/คืนข้อมูล | `exports`, system-reset | ⚠️ ไม่มี restore |

## 7. ลำดับที่แนะนำ (ต่อจากแผน Express phase 1)

1. **SO + ตัดสต็อกตอน IV + COGS** (QT → SO → IV → RE ครบ flow) ← gap ใหญ่สุด
2. **Master คลัง + ต้นทุนถัวเฉลี่ย + สต็อกการ์ด** (ยอด/มูลค่าวิ่ง)
3. **ลดหนี้ซื้อ (RRGR)** กลับรายการ AP/GL/ภาษีซื้อ
4. **ยอดยกมา + ปิดงวด/ปิดปี**
5. เช็ค: ผ่านเช็ค + กระทบยอดธนาคาร; พนักงานขาย + วงเงินเครดิต; รายงานวิเคราะห์ขาย/ซื้อ
